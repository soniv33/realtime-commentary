The commentary will stream here, token by token…

Pick any race from 2023 onwards and this page fetches its real telemetry from the OpenF1 API, distils it into multi-signal events, and runs the real dual-streaming pipeline in your browser: telemetry → a fast LLM token stream → a punctuation chunker → ElevenLabs’ Flash streaming-input WebSocket → Web Audio playback, with a live broadcast-offset. It’s the browser twin of the Python backend in this repo (src/f1_commentator/), and the distillation is a direct port of simulator/openf1.py — so what you hear is exactly how the system would respond to a live feed.

event ─▶ commentary token stream ─▶ chunk_by_punctuation ─▶ ElevenLabs stream-input WS ─▶ broadcast offset ─▶ speakers (scripted, or real Claude Haiku) (earliest boundary) (real audio, PCM 16 kHz)

Why keys are entered at runtime

GitHub Pages is static — there’s no server to hold a secret. The production system keeps keys behind the Python backend (or a serverless proxy); this static demo asks the presenter to paste their own ElevenLabs key, which lives only in this browser tab and is never committed. With no key, the demo still shows the full streaming/chunking behaviour — just muted.
